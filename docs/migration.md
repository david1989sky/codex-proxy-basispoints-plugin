# 迁移标记

插件第一次打开时会从 companion Worker 检查健康状态。点击「确认迁移」后，插件通过 `host.state.put` 在 `twofa/migration` 保存一条小型状态记录：版本、加密凭据挂载状态、记录数量和更新时间。

这个动作不会复制账号、密码、TOTP、密钥、浏览器文件或截图。Worker 继续读取现有的 AES-256-GCM 凭据目录，因此升级插件不会改变账号数据的位置和加密格式。

迁移接口是幂等的。已存在有效标记时再次确认只读取并返回原标记；状态版本不匹配或宿主状态服务不可用时，页面显示错误并保留原有 Worker 数据。

升级时只需要让新插件读取同一个 `twofa/migration` 标记，并把 Worker 镜像更新到同一 Release 的摘要。回滚插件或 Worker 不会删除这条标记，也不会回滚加密凭据。
